# راهنمای ذخیره دیتا در هاست اشتراکی 🗄️

این راهنما برای انتقال و ذخیره‌سازی **دیتای سامانه مدیریت تولید** روی **هاست اشتراکی (cPanel)** تهیه شده است.

---

## کدام حالت برای شما مناسب است؟

| حالت | شرح | مناسب برای |
|------|------|-----------|
| **راه اول (پیشنهادی)** | برنامه روی کامپیوتر اجرا می‌شود (نسخه دسکتاپ یا سرور محلی) ولی **دیتا در MySQL هاست** ذخیره می‌شود | اکثر هاست‌های اشتراکی که فقط PHP + MySQL دارند |
| **راه دوم** | **کل برنامه (سرور) روی هاست** نصب می‌شود — نیازمند Node.js روی هاست | هاست‌هایی که در cPanel گزینه «Setup Node.js App» دارند |

در هر دو حالت، دیتا در دیتابیس MySQL هاست شما ذخیره می‌شود و از هر کامپیوتر دیگری (با اتصال اینترنت) به همان دیتا دسترسی دارید — یعنی چند کامپیوتر همزمان با یک دیتای مشترک کار می‌کنند.

---

## 📤 گام صفر: از دیتای فعلی خروجی بگیرید (برای هر دو راه)

قبل از هر تغییری، از دیتای موجود در نسخه فعلی یک **بکاپ JSON** بگیرید:

1. برنامه را باز کنید و با اکانت **admin** وارد شوید
2. منوی **تنظیمات** → بخش **پشتیبان‌گیری خودکار و دستی**
3. روی دکمه **«خروجی JSON (انتقال به هاست)»** کلیک کنید
4. فایل `backup-....json` دانلود می‌شود — **آن را در جای امنی نگه دارید**

این فایل شامل همه چیز است: کاربران، محصولات، مواد اولیه، فرمول‌ها، سفارشات تولید، فروش‌ها، مشتریان، انبار، مصارف، کارکنان و تنظیمات.

# 🟢 راه اول: دیتا در هاست، برنامه روی کامپیوتر

## گام ۱ — در cPanel هاست: دیتابیس MySQL بسازید

1. وارد **cPanel** هاست شوید
2. بخش **Databases** → **MySQL® Databases** را باز کنید
3. در قسمت *Create a New Database* یک نام بنویسید (مثلاً `mfgdb`) و **Create Database** بزنید
   - نام کامل معمولاً به‌شکل `USERNAME_mfgdb` می‌شود — یادداشتش کنید
4. پایین‌تر، در *Add New User*: نام کاربری (مثلاً `mfguser`) و یک **رمز قوی** بسازید → **Create User**
5. در *Add User to Database*: کاربر و دیتابیس را انتخاب → **Add**
6. در صفحه بعدی تیک **ALL PRIVILEGES** را بزنید → **Make Changes**

## گام ۲ — دسترسی از راه دور (Remote MySQL)

چون برنامه روی کامپیوتر شما اجرا می‌شود، هاست باید اجازه اتصال بدهد:

1. در cPanel → **Remote MySQL** (یا Remote Database Access)
2. در قسمت *Host* علامت `%` را وارد کنید → **Save**
   - امن‌تر: فقط IP اینترنت خود را وارد کنید (جستجو کنید «my ip»)
3. ⚠️ اگر گزینه Remote MySQL در هاست شما نبود یا بعداً برنامه نتوانست وصل شود (خطای اتصال)، با پشتیبانی هاست تماس بگیرید و بگویید: **«پورت 3306 برای دسترسی خارجی MySQL باز شود»** — بعضی هاست‌ها این امکان را محدود می‌کنند.

## گام ۳ — ساخت جداول در هاست (phpMyAdmin)

1. در cPanel → **phpMyAdmin**
2. از فهرست سمت چپ، دیتابیس ساخته‌شده (`USERNAME_mfgdb`) را انتخاب کنید
3. تب **Import** → فایل **`mysql-schema.sql`** (ضمیمه این پروژه در پوشه `docs/`) را انتخاب کنید
4. دکمه **Go** را بزنید → پیام سبزرنگ موفقیت
5. حالا ۱۹ جدول سامانه در هاست ساخته شده است

> این فایل فقط **ساختار خالی** جداول را می‌سازد؛ دیتای شما در گام ۶ منتقل می‌شود.

## گام ۴ — برنامه را به هاست وصل کنید

### الف) نسخه دسکتاپ ۱.۰.۳ یا جدیدتر — از داخل خود برنامه (ساده‌ترین روش) ✨

1. برنامه را باز کنید و با اکانت **admin** وارد شوید
2. منوی **تنظیمات** → کارت **«اتصال برنامه به هاست (ذخیره دیتا در MySQL)»**
3. اطلاعات هاست را وارد کنید:
   - **آدرس هاست**: مثل `server1.myhost.com` (در cPanel بخش *General Information* نوشته شده)
   - **پورت**: معمولاً `3306`
   - **نام دیتابیس**، **نام کاربری** و **رمز**: همان‌هایی که در گام ۱ ساختید
4. روی **«ذخیره و اتصال به هاست»** بزنید — برنامه خودش فایل تنظیمات را می‌نویسد و دوباره باز می‌شود

> ✅ دیگر نیازی به پیدا کردن دستی فایل `db-connection.txt` نیست — برنامه همه‌چیز را خودکار انجام می‌دهد (حتی رمزهای دارای کاراکتر خاص مثل `@`).
>
> 📁 با دکمه **«باز کردن پوشه تنظیمات»** می‌توانید پوشهٔ فایل تنظیمات (`%APPDATA%\ManufacturingERP`) را مستقیم در ویندوز باز کنید.
>
> ↩️ برای برگشتن به دیتابیس محلی، دکمه **«بازگشت به دیتابیس محلی»** در همان کارت است.

### ب) نسخه‌های قدیمی‌تر — روش دستی با فایل db-connection.txt

1. بسته برنامه را باز کنید (اگر در حال اجراست، ببندید)
2. در پوشه اطلاعات برنامه، فایل **`db-connection.txt`** را پیدا کنید:
   - Windows: کلیدهای `Win + R` → تایپ کنید `%APPDATA%\ManufacturingERP` → Enter
   - فایل `db-connection.txt` را با **Notepad** باز کنید
3. خط نمونه آخر فایل را ویرایش کنید و `#` ابتدای آن را بردارید:

```
mysql://USERNAME_DBUSER:PASSWORD@HOST_ADDRESS:3306/USERNAME_DBNAME
```

مثال واقعی (اطلاعات را از هاست خودتان بگذارید):

```
mysql://myshop_mfguser:Str0ngP%40ss@server1.myhost.com:3306/myshop_mfgdb
```

4. فایل را ذخیره کنید و برنامه را دوباره باز کنید

> 🔑 **نکته رمز عبور:** اگر رمز شما کاراکترهای خاص دارد باید تبدیل شوند: `@` → `%40` ، `#` → `%23` ، `&` → `%26` ، `:` → `%3A`
> مثال: رمز `Abc@123` می‌شود `Abc%40123`
>
> 📌 آدرس هاست (HOST_ADDRESS) معمولاً در cPanel نوشته شده (مثل `server1.myhost.com`) یا در بخش General Information → Shared IP Address.

### ج) نسخه سروری (اگر برنامه را با npm/bun اجرا می‌کنید)

1. در فایل `.env` کنار پروژه، خط `DATABASE_URL` فعلی را با `#` کامنت کنید و خط MySQL را فعال کنید:

```
# DATABASE_URL=file:./db/custom.db
DATABASE_URL=mysql://USERNAME_DBUSER:PASSWORD@HOST_ADDRESS:3306/USERNAME_DBNAME
```

2. دستورات زیر را اجرا کنید:

```bash
bun run db:push:mysql      # ساخت/همگام‌سازی جداول در هاست (جایگزین گام ۳ هم می‌شود)
bun run db:generate:mysql  # آماده‌سازی کلاینت دیتابیس MySQL
```

3. برنامه را ری‌استارت کنید

## گام ۵ — اولین ورود با دیتابیس خالی هاست

وقتی برنامه با دیتابیس خالی هاست بالا بیاید و جدول کاربران خالی باشد، سامانه **به‌صورت خودکار** یک حساب ادمین موقت می‌سازد:

- نام کاربری: `admin`
- رمز: `admin123`

## گام ۶ — انتقال دیتای قبلی به هاست

1. با `admin` / `admin123` وارد شوید
2. **تنظیمات** → **پشتیبان‌گیری** → دکمه **«آپلود و بازیابی»**
3. همان فایل **JSON** گام صفر را انتخاب کنید
4. پیام موفقیت: همه دیتای قبلی (کاربران، محصولات، فروش‌ها...) حالا در هاست ذخیره شده است
5. خروج بزنید و با **اکانت اصلی خودتان** وارد شوید (اکانت‌های قبلی شما برگشته‌اند)

✅ **تمام!** از این لحظه هر تراکنشی (فروش، تولید، انبار...) مستقیماً در دیتابیس هاست ذخیره می‌شود. روی هر کامپیوتر دیگری هم همین برنامه را نصب کنید و همان `db-connection.txt` را با همان خط mysql تنظیم کنید — همه به یک دیتای مشترک وصل می‌شوند.

> 🔄 در تنظیمات → پشتیبان‌گیری، نشان **«ذخیره‌سازی: هاست MySQL»** را می‌بینید که یعنی اتصال به هاست برقرار و فعال است. در این حالت بکاپ‌های خودکار به‌صورت **اسنپ‌شات JSON** گرفته می‌شوند.

# 🟡 راه دوم: نصب کامل برنامه روی هاست (فقط با Node.js)

فقط اگر در cPanel شما گزینه **Setup Node.js App** (یا Node.js Selector) وجود دارد ادامه دهید؛ وگرنه از راه اول استفاده کنید.

## گام ۱ — دیتابیس MySQL بسازید
مانند راه اول (گام ۱) + جداول را با `mysql-schema.sql` در phpMyAdmin ایمپورت کنید (گام ۳).

## گام ۲ — آپلود فایل‌های پروژه

1. فایل ZIP پروژه را آماده کنید (بدون پوشه‌های `node_modules` و `.next`)
2. در cPanel → **File Manager** → پوشه `~/app` بسازید و ZIP را آنجا آپلود و Extract کنید

## گام ۳ — ساخت اپلیکیشن Node.js

1. cPanel → **Setup Node.js App** → **Create Application**
2. تنظیمات:
   - Node.js version: **18 یا بالاتر** (20 بهتر)
   - Application mode: **Production**
   - Application root: `app` (همان پوشه آپلود)
   - Application URL: دامنه شما
   - Application startup file: `server.js` — دستوری زیر را هم در **Startup command** بگذارید اگر فیلد جداگانه دارد: `npm start`
3. **Create** بزنید

## گام ۴ — متغیرهای محیطی

در همان صفحه اپلیکیشن، بخش **Environment variables**:

| Name | Value |
|------|-------|
| `DATABASE_URL` | `mysql://USERNAME_DBUSER:PASSWORD@localhost:3306/USERNAME_DBNAME` |
| `NODE_ENV` | `production` |

> روی هاست، آدرس دیتابیس معمولاً `localhost:3306` است (نه IP خارجی)، چون برنامه خودش روی همان سرور است.

## گام ۵ — نصب و اجرا (ترمینال cPanel)

cPanel → **Terminal** (یا از صفحه Node.js App دکمه **Run NPM Install**):

```bash
cd ~/app
npm install            # یا: bun install
npx prisma generate --schema prisma/schema.mysql.prisma
npx prisma db push --schema prisma/schema.mysql.prisma --accept-data-loss
npm run build
```

بعد در صفحه Setup Node.js App دکمه **Restart** را بزنید.

## گام ۶ — انتقال دیتا

مانند گام‌های ۵ و ۶ راه اول: ورود با `admin/admin123` → آپلود بکاپ JSON → تمام.

---

## 🔒 نکات امنیتی مهم

1. **رمز ادمین موقت** (`admin123`) را بعد از بازیابی بکاپ عوض کنید (کاربران → حساب خود را ویرایش کنید)
2. رمز دیتابیس MySQL را قوی انتخاب کنید و آن را در فایل‌های عمومی قرار ندهید
3. اگر هاست شما SSL دیتابیس دارد، در انتهای DATABASE_URL اضافه کنید: `?sslaccept=strict`
4. بکاپ‌های JSON را دوره‌ای دانلود و روی کامپیوتر شخصی آرشیو کنید

## ❓ مشکلات رایج

| مشکل | راه‌حل |
|------|--------|
| برنامه باز می‌شود ولی خطای «ارتباط با سرور» یا قطع شدن | `DATABASE_URL` اشتباه است — در لاگ برنامه (`%APPDATA%\ManufacturingERP\electron.log`) خطای اتصال را ببینید |
| خطای `Access denied for user` | نام کاربری/رمز دیتابیس غلط است؛ رمز با کاراکتر خاص باید URL-encode شود |
| خطای `Host ... is not allowed to connect` | Remote MySQL تنظیم نشده — گام ۲ راه اول |
| خطای `Can't connect to server on ... (10060/timeout)` | پورت 3306 بسته است — با پشتیبانی هاست تماس بگیرید |
| خطای `Table ... doesn't exist` | جداول ساخته نشده‌اند — گام ۳ (phpMyAdmin Import) یا `db:push:mysql` |
| دیتابیس پر است (خطای Disk quota / Max connections) | هاست‌های اشتراکی محدودیت دارند؛ تعداد بکاپ‌ها را کم کنید و با هاست چک کنید |
