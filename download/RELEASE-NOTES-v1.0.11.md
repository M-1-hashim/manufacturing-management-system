# Release Notes — v1.0.11

## زبان خالص دری افغانستانی + فونت B Nazanin

### فونت جدید: B Nazanin (بی نازنین)
- فونت آپلودی کاربر (B-NAZANIN.TTF) فونت اصلی کل سیستم شد — همان فونت رسمی و دودیز اسناد در افغانستان
- font-stack: «B Nazanin → Vazirmatn → system» — حروف خاص پشتو (ټ ډ ړ ږ ښ ګ ې ۍ) و حروف لاتین به‌طور خودکار از Vazirmatn نمایش داده می‌شود
- جبران اندازه فونت: در حالت دری/پشتو کل رابط ۱۲٪ بزرگ‌تر می‌شود تا B Nazanin درشت و خوانا باشد (انگلیسی ۱۰۰٪)
- فونت داخل نصب‌کننده و نسخهٔ پرتابل قرار دارد — کاملاً آفلاین کار می‌کند

### دری خالص افغانستانی در همهٔ ۱۳ ماژول (~۱۰۵۰ اصلاح واژگان)
- کاربر → استفاده‌کننده | ویرایش → تصحیح | تأیید → تصدیق | جزئیات → تفصیلات
- فرمول → فورمولا | فرم → فورم | هزینه → مصارف | حقوق → معاش | دستمزد → اجرت
- حضور و غیاب → حاضری | تاریخ انقضا → تاریخ ختم | باقی‌مانده/مانده → باقیات
- دلار → دالر | نرخ ارز → اسعار | اینترنت → انترنت | به‌روزرسانی → تجدید
- بارگذاری → بارگیری | پشتیبان‌گیری/بکاپ → کاپی احتیاطی | نمودار → چارت
- شماره → نمبر | تلفن → تیلیفون | نام خانوادگی → تخلص | منابع انسانی → منابع بشری
- اطلاعات → معلومات | افزودن/اضافه کردن → علاوه کردن | تلاش → کوشش | رمز → پاسورد
- سرور → هاست | عملیات → اجراؤات | اعتباری → نسیه | برنامه/دسته‌بندی → پلان/کتگوری
- بزرگ‌تر/بیشتر → زیادتر | احراز هویت → تصدیق هویت | سربرگ → سرلوحه
- ورود/خروج (لاگین/لاگ‌اوت) → داخل شدن/خارج شدن | با موفقیت → با کامیابی
- معانی درست حفظ شد: ورود/خروج مواد (انبار)، ورود/خروج امروز (حاضری)، انتقال دیتا
