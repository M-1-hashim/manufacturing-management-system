# ManufacturingERP — نسخهٔ ۱.۰.۹ (v1.0.9)

## ✨ تازه‌ها

### ۱) ویزارد راه‌اندازی اولیه — اولین باز شدن برنامه
بعد از نصب، برنامه خودش تنظیمات را از شما می‌پرسد:
- انتخاب زبان (دری / پښتو / English) و رنگ دلخواه
- انتخاب محل دیتا: **فقط این دستگاه** یا **هاست اینترنتی**
- فرم اتصال هاست: تونل SSH (هاست اشتراکی Namecheap/cPanel) یا مستقیم (VPS) با دکمهٔ «تست اتصال»
- راهنمای سه‌مرحله‌ای cPanel داخل خود ویزارد
> نکته: برای نمایش دوبارهٔ ویزارد، برنامه را با آدرس `?setup=1` باز کنید.

### ۲) ساخت خودکار جدول‌ها روی هاست — دیگر phpMyAdmin لازم نیست
وقتی برنامه برای اولین بار به هاستِ تازه وصل می‌شود، **هر ۱۹ جدول به‌صورت خودکار ساخته می‌شوند** و اگر هاست خالی باشد، کاربران و تنظیمات دستگاه شما هم کپی می‌شود — یعنی بلافاصله بعد از اتصال می‌توانید با همان admin/admin123 وارد شوید.

### ۳) انتقال دیتای دستگاه به هاست (یک کلیک)
در تنظیمات → اتصال به هاست: دکمهٔ **«انتقال دیتای این دستگاه به هاست»** — همهٔ محصولات، مشتریان، فاکتورها و… به هاست منتقل می‌شود (برای کسانی که قبلاً بدون هاست کار می‌کردند).

### ۴) طراحی جدید + ۱۱ تم رنگی
- صفحهٔ ورود کاملاً جدید (پنل معرفی + فرم شیشه‌ای روی پس‌زمینهٔ گرادیانی)
- منوی کنار گروه‌بندی‌شده (عملیات روزانه / مدیریت / سیستم) با نشانگر فعال
- ۴ تم جدید: سبز، قهوه‌ای، سرخابی، اقیانوسی → مجموعاً **۱۱ تم**
- گالری تم در تنظیمات → «ظاهر برنامه» + دکمهٔ روشن/تیره

## 🧪 تست شده
- هر ۱۹ جدول روی MariaDB واقعی ساخته و راستی‌آزمایی شد (اجرای تکراری هم امن است)
- تست کامل نقطه‌به‌نقطهٔ هر ۱۳ ماژول: ساخت/ویرایش/حذف، سه زبان، راست‌به‌چپ، موبایل، تم تیره
- بوت‌استرپ: کپی کاربران/تنظیمات به هاست خالی ✓ — انتقال کامل دیتا ✓
