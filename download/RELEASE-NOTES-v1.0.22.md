# نسخهٔ ۱.۰.۲۲ — پیام‌های واضح برای «وصل نمی‌شود» + راهنمای اتصال

این نسخه مستقیماً در پاسخ به این بازخورد منتشر شد: **«فقط آدرس سرور را می‌خواهد و اینکه وصل هم نمی‌شود»** — حالا هر وقت تست اتصال ناموفق باشد، برنامه **علت واقعی را به زبان ساده** می‌گوید و می‌گوید چه کاری باید بکنید؛ به‌علاوه چند مشکل واقعی اتصال رفع شده است.

## چه چیزی عوض شد؟

### اندروید (APK) — صفحهٔ اتصال سرور
- **پیام خطای واضح به‌جای خطای فنی**: تا الان فقط «پاسخی دریافت نشد» می‌دیدید؛ حالا علت دقیق نمایش داده می‌شود:
  - *آدرس پیدا نشد* → املای آدرس یا انترنت
  - *سرور پاسخ نداد (تایم‌اوت)* → انترنت یا فایروال سرور
  - *اتصال رد شد* → سرور در دسترس نیست یا پورت/پروتکل اشتباه
  - **«روی این آدرس نسخهٔ وب برنامه اجرا نمی‌شود»** → مهم‌ترین حالت: آدرسی وارد شده که سایت است ولی نسخهٔ وب برنامه روی آن نصب نیست
  - جزئیات فنی خام هم زیر پیام اصلی (حروف کوچک) می‌آید
- **رفع مشکل واقعی «وصل نمی‌شود»**: اگر آدرس را بدون `http://` یا `https://` وارد کنید، برنامه اول `https` و بعد `http` را امتحان می‌کند — هاست‌های بدون گواهی SSL قبلاً همیشه شکست می‌خوردند. آدرسی که واقعاً جواب داد ذخیره می‌شود (کنار پیام سبز هم نوشته می‌شود)
- **بخش راهنمای جدید**: «تست وصل نشد؟ یا آدرس سرور را ندارید؟ — راهنما» توضیح می‌دهد:
  - «آدرس سرور» یعنی آدرسی که **نسخهٔ وب** برنامه روی آن نصب است
  - چرا گوشی نمی‌تواند مستقیم به MySQL وصل شود و دو راه‌حل چیست (نسخهٔ ویندوز که مستقیم وصل می‌شود / نصب نسخهٔ وب روی سرور)

### دسکتاپ (ویندوز) — صفحهٔ اطلاعات هاست (اولین اجرا)
- **تست SSH حالا علت شکست را دقیق می‌گوید** و پیام کامل داخل همان صفحه می‌ماند (قبلاً فقط یک پیام کوتاه لحظه‌ای بود):
  - نام کاربری/پسورد اشتباه → یادآوری اینکه این‌ها همان مشخصات cPanel هستند نه MySQL
  - سرور پاسخ نداد → معمولاً SSH روشن نیست یا پورت اشتباه است (اشتراکی: ۲۱۰۹۸)
  - آدرس پیدا نشد / اتصال رد شد → پیام مربوطه + جزئیات فنی
- **چک‌لیست رفع مشکل** زیر دکمهٔ تست: روشن‌کردن SSH در cPanel (Manage Shell Access)، پورت درست، مشخصات cPanel (نه MySQL)، آدرس بدون `https://`

### فنی
- `probeHost` بازنویسی شد: دسته‌بندی علت شکست (DNS / TIMEOUT / CONN / NOT_APP / HTTP / SERVER_ERROR)، تلاش مجدد با http، برگرداندن `triedUrl`
- ذخیرهٔ آدرس در ویزارد اندروید و کارت تنظیمات از `triedUrl` استفاده می‌کند (قبلاً https اجباری ذخیره می‌شد حتی وقتی http جواب می‌داد — باگ واقعی)
- نسخه‌ها: برنامه ۱.۰.۲۲ · نصاب ویندوز ۱.۰.۲۲.۰ · اندروید versionCode 7

## اگر هنوز «وصل نمی‌شود»

1. **گوشی**: آدرس باید آدرسِ نسخهٔ وب نصب‌شده باشد (مثل `https://erp.example.com`) — آدرس خالیِ هاست (cPanel بدون نسخهٔ وب) هرگز جواب نمی‌دهد. اگر نسخهٔ وب ندارید: نسخهٔ ویندوز را نصب کنید که مستقیم به دیتابیس هاست وصل می‌شود
2. **ویندوز (تونل SSH)**: در cPanel بخش **Manage Shell Access** دسترسی SSH را روشن کنید؛ پورت Namecheap معمولاً **۲۱۰۹۸** است؛ نام کاربری/رمز همان cPanel است
3. بعد از هر تغییری دکمهٔ **تست** را بزنید — حالا پیام می‌گوید دقیقاً چه چیزی نادرست است
